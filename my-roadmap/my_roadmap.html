📌 Куда вставлять JavaScript?

Есть два основных места:

  1. Внутри <head> — но тогда скрипт загружается до того, как браузер создаст страницу, и может не найти элементы (потому что их ещё нет). Поэтому для новичков лучше использовать второй способ.

  2. Перед закрывающим </body> — скрипт загружается после того, как вся страница уже построена. Это самый надёжный способ.

Мы используем второй способ:

// 1. Найти все кнопки с классом "done"
const buttons = document.querySelectorAll('.done');

// 2. Для каждой кнопки добавить обработчик клика
buttons.forEach(function(btn) {
    btn.addEventListener('click', function() {
        // 3. Найти карточку, в которой находится кнопка
        const card = this.parentElement;

        card.classList.toggle('completed');

        } else {
            this.textContent = 'Изучено';
        }
    });
});

🧩 Объяснение каждой строчки (максимально просто)

Строка 1: const buttons = document.querySelectorAll('.done');

  • Что делает: Ищет все элементы с классом done (это наши кнопки).

  • Как работает: document — это вся страница. querySelectorAll — команда «найти все». В скобках мы пишем, что ищем (.done). Результат сохраняем в переменную buttons.

  • Зачем: Чтобы мы могли работать с каждой кнопкой по отдельности.

Строка 2: buttons.forEach(function(btn) { ... });

  • Что делает: Выполняет код внутри фигурных скобок для каждой кнопки.

  • Как работает: forEach — это цикл. Он перебирает все кнопки из списка buttons. Каждую кнопку он передаёт в функцию как аргумент (мы назвали его btn).

  • Зачем: Чтобы мы могли прикрепить обработчик клика к каждой кнопке.

Строка 3: btn.addEventListener('click', function() { ... });

  • Что делает: Говорит: «Когда по этой кнопке кликнут, выполни код внутри фигурных скобок».

  • Как работает: addEventListener — команда «слушай событие». В скобках мы пишем тип события ('click') и функцию, которая выполнится при клике.

  • Зачем: Чтобы при клике на кнопку происходило что-то полезное.

Строка 4: const card = this.parentElement;

  • Что делает: Находит карточку, внутри которой находится кнопка.

  • Как работает: this — это сама кнопка. parentElement — это её родительский элемент (в нашем случае <div class="card">). Сохраняем его в переменную card.

  • Зачем: Чтобы мы могли менять карточку (цвет, класс), а не кнопку.

Строка 5: card.classList.toggle('completed');

  • Что делает: Переключает класс completed на карточке.

  • Как работает: classList — это список классов элемента. toggle — команда «включи/выключи». Если класса нет — добавляет, если есть — удаляет.

  • Зачем: Чтобы карточка меняла внешний вид (становилась зелёной и обратно).

Строка 6–9: if (card.classList.contains('completed')) { ... } else { ... }

  • Что делает: Проверяет, есть ли у карточки класс completed, и меняет текст кнопки.

  • Как работает: contains — команда «проверь, есть ли такой класс». Если есть — меняем текст на '✅ Изучено'. Если нет — возвращаем 'Изучено'.

  • Зачем: Чтобы пользователь видел, что этап отмечен или снят.

🔍 Почему код серый?

То, что ты видишь серый текст, — это отсутствие подсветки синтаксиса в VS Code. Это не ошибка и не значит, что код не работает. Просто VS Code «не знает», что это JavaScript, потому что мы написали его внутри тега <script>.

Подсветка синтаксиса — это когда разные части кода окрашиваются в разные цвета (синий, зелёный, жёлтый), чтобы было удобнее читать. Без неё всё выглядит однообразно, но работает точно так же.

⚙️ Как включить подсветку для JS

Чтобы VS Code начал «видеть» JavaScript внутри HTML, нужно установить расширение, которое умеет подсвечивать синтаксис. Это делается для удобства, но не для работы.

Вот несколько расширений, которые тебе пригодятся:

РасширениеЗачем
HTML CSS SupportПодсвечивает HTML, CSS и JavaScript внутри HTML.
JavaScript (ES6) code snippetsДобавляет быстрые заготовки кода и улучшает подсветку.
Russian Language PackПереводит интерфейс VS Code на русский (уже должен быть установлен).

📌 Как установить расширение

  1. Нажми на иконку «Расширения» на левой панели (или нажми Ctrl+Shift+X).

  2. В поиске напиши HTML CSS Support.

  3. Нажми «Установить».

После установки закрой и открой файл index.html заново. Теперь твой JavaScript должен стать цветным.

🧠 Почему JS выглядит «неэстетично»

  1. Нет форматирования — ты написал код в одну строку или с хаотичными отступами? Это делает его визуально шумным.

  2. Моноширинный шрифт — все символы одинаковой ширины, из-за чего код выглядит плотнее, чем обычный текст.

  3. Цвета по умолчанию — если не установлены расширения для подсветки, весь код серый. Это действительно утомляет.

  4. Много скобок и точек — синтаксис JS действительно более «символьный», чем CSS.

✨ Как сделать JS красивым и удобным для глаз

1. Включи автоформатирование (Prettier)

Самое важное — чтобы код автоматически выравнивался, когда ты сохраняешь файл.

  • Установи расширение Prettier (если ещё нет).

  • Настрой автоформатирование при сохранении:

    • Нажми Ctrl + , (открыть настройки).

    • В поиске напиши format on save.

    • Поставь галочку ✅ Editor: Format On Save.

  • Теперь, когда ты нажимаешь Ctrl+S, код сам выстраивается в аккуратную структуру.

2. Установи тему оформления (например, Dark+)

Тёмная тема делает код контрастнее, а значит — читаемее.

  • Нажми Ctrl + Shift + P.

  • Напиши Color Theme и выбери Dark+ (default dark) или One Dark Pro (если установишь расширение).

3. Установи подсветку синтаксиса

Без неё весь код серый. Установи расширение HTML CSS Support — оно добавит цвета для JS внутри HTML.

4. Используй сниппеты (заготовки)

Чтобы не писать длинные конструкции вручную:

  • Напиши log и нажми Tab — появится console.log().

  • Напиши cl → Tab → появится console.log() с выделенным местом для текста.
