Моя дорожная карта

Данный проект представляет собой мою личную дорожную карту для освоения Fullstack-разработки. План включает последовательное изучение технологий от вёрстки до создания полноценных веб-приложений с бэкендом и деплоем.

Этап 1: HTML

Изучаются основы структуры веб-страницы: основные теги для заголовков, абзацев, списков, ссылок, изображений, таблиц и форм. Осваивается семантическая разметка, позволяющая правильно структурировать контент с помощью элементов header, nav, main, section, article и footer. Также рассматриваются правила вложенности и доступности.

Этап 2: CSS

Изучаются способы оформления страниц: работа с цветами, шрифтами, отступами, рамками и фонами. Осваиваются селекторы по тегу, классу и идентификатору, а также принципы каскадности и специфичности. Рассматривается блочная модель и использование псевдоклассов.

Этап 3: Flexbox и Grid

Осваиваются современные методы раскладки блоков. Изучаются свойства Flexbox для управления направлением, выравниванием и распределением пространства, а также Grid для создания сложных сеток. Рассматриваются медиа-запросы для адаптации под различные устройства.

Этап 4: JavaScript

Изучаются базовые конструкции языка: переменные, типы данных, условные операторы, циклы и функции. Рассматривается работа с массивами и объектами, а также использование стрелочных функций для упрощения кода.

Этап 5: DOM и события

Осваивается работа с DOM: поиск элементов на странице, изменение их содержимого и стилей. Рассматривается обработка событий, таких как клик, ввод текста и отправка форм, а также управление классами элементов.

Этап 6: Хранение данных на клиенте

Изучаются механизмы локального хранения данных в браузере через localStorage и sessionStorage. Осваиваются методы сохранения, извлечения и удаления данных, а также сериализация и десериализация объектов в формат JSON.

Этап 7: Бэкенд на C#

Изучается создание серверной части с использованием ASP.NET Core. Рассматриваются структура проекта, создание контроллеров, маршрутизация и модели данных. Осваиваются основные методы HTTP-запросов и работа с форматом JSON. Также затрагиваются основы подключения базы данных.

Этап 8: Интеграция фронта и бэка

Осваивается отправка HTTP-запросов с клиентской части с помощью fetch. Рассматриваются методы GET, POST, PUT и DELETE, а также обработка ответов от сервера. Изучается обновление интерфейса на основе полученных данных и взаимодействие с API.

Этап 9: Git и деплой

Изучаются основы работы с Git: инициализация репозитория, создание коммитов, работа с ветками и слияниями. Рассматривается публикация проектов на GitHub и их размещение на бесплатных хостингах для статических и динамических приложений.

Этап 10: Финальный проект

Разрабатывается полноценное приложение от начала до конца: выбор темы, проектирование архитектуры, создание базы данных, разработка API и интерфейса, интеграция компонентов, тестирование и устранение ошибок. Завершается проект подготовкой презентации и защитой.
